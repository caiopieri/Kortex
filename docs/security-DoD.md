# Security Definition of Done

O checklist detalhado do motor esta em
[`motor/docs/security-DoD.md`](../motor/docs/security-DoD.md). Esse documento e a fonte
normativa atual para mudancas no backend; outros projetos devem manter um checklist proprio
quando suas fronteiras divergirem.

Ausencia de um controle deve ser registrada como `bloqueado`, nunca convertida em `N/A` para
aprovar o gate.
