06. Rules: Do's and Don'ts

DO

  • Render all telemetry graphs, radar rings, and card slots with thin 1px lines (`var(--color-border)`).
  • Use IBM Plex Mono for execution logs, tables, rates, latencies, and token counters.
  • Keep status signals and alert tones subtle and low-saturation.
  • Align cards to the grid structure to project organization and control.

DON'T

  • Don't use neon glows, drop shadows, or light blooms that cause ciliary strain.
  • Don't implement pill-shaped buttons or excessive rounding: restrict radius to 2px/4px.
  • Don't add non-functional animations or decorative elements that cause cognitive load.
  • Don't use saturated primary colors as dominant card backgrounds.
