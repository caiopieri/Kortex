# Primeiro prompt para o Codex

Cole este prompt no outro Codex quando abrir esta pasta.

```text
Estamos testando um piloto chamado "Projeto Publicavel com XP/TDD Lite".

Objetivo:
Criar um projeto pequeno, mas com padrao minimo de projeto aberto real: instalacao simples, testes, CI, README orientado ao problema, docs tecnicas curtas e comandos padronizados.

Nome do projeto:
sistema-canivete

Ideia inicial:
Quero construir um sistema-canivete: uma ferramenta pequena, util e extensivel, mas ainda nao quero que voce comece codando. Primeiro quero que voce me ajude a definir o problema, usuario, caso de uso, instalacao ideal, stack, fora de escopo e primeira fatia XP/TDD.

Regras:
- Nao comece pela stack. Comece pelo problema e caso de uso.
- Nao codifique ainda.
- Nao faca spec-kit completo.
- Mantenha o piloto pequeno.
- Se a ideia estiver grande demais, corte escopo.

Antes de codar, me devolva:
1. problema que isso resolve;
2. usuario-alvo;
3. exemplo de uso;
4. instalacao ideal em um comando;
5. stack sugerida, com justificativa curta;
6. fora de escopo;
7. primeira fatia XP/TDD;
8. onde isto pode dar errado.

Depois que eu aprovar, atualize docs/PROJECT-BRIEF.md e proponha a Tarefa 0.
```
