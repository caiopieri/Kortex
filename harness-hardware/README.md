# Hardware harness

This directory explores how Kortex's evidence and artifact contracts extend to hardware
workflows. The current blueprint covers diagnosis, design artifacts, deterministic validation
and the irreducible physical feedback loop.

The harness is conceptual and not production-certified. Start with
`HARNESS-HARDWARE-diagnostico-e-blueprint.md`; runtime requirements must be expressed as
versioned `WorkflowSpec` contracts and causal tests in the motor.
